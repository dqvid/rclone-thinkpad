# Privacy policy

*rclone thinkpad* is a personal, single-user setup of the open-source tool [rclone](https://rclone.org). It is used only by its owner, to reach the owner's own Google Drive.

## What data is accessed

With the owner's permission, it accesses the owner's own Google Drive files and file information (Google scopes drive, docs and drive.metadata.readonly), so they can be opened and saved from the owner's laptop.

## What happens to it

Data travels only between Google and the owner's own computer. Nothing is collected, sent to any other server, shared, sold, or used for advertising. The sign-in token is stored only on the owner's computer, in an encrypted file. This website uses no cookies or analytics.

The use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

Access can be withdrawn at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
